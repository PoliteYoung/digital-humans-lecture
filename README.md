## Presenting the slides

Part 1: open `index.html`. Part 2: open `digital-spaces-deck/index.html` (a single self-contained file). Both work offline in Chrome or Edge.

| Key | Action |
|---|---|
| → / Space / left click / wheel | next |
| ← / right click | back |
| S | speaker view (notes + timer) |
| F | full screen |
| Esc / O | overview |
| T | switch light / dark theme (Part 1; light is the default) |
| B | black screen |

Export a PDF backup: open `index.html?print-pdf` → Print → Save as PDF (landscape, no margins, background graphics on).

## Contents

- 12 slides, ~27 min, with speaker notes on every slide
- Storyline: a digital human = **Representation** (mesh / pixels / implicit / Gaussians) + **Driving** (skeleton / parametric / generative)
- Slides 1 and 7 use a real DREAMS studio capture of the presenter: NeuS mesh from the studio pipeline, and a 3D Gaussian Splatting model trained with [Brush](https://github.com/ArthurBrussee/brush) on a MacBook (24 views, ~95k Gaussians, ~30 min).
