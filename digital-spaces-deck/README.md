# Digital Spaces · 本地 HTML 课件

## 打开

双击 `index.html`，使用 Chrome 或 Edge 打开。无需安装依赖、启动服务器或连接网络。
**这个 HTML 是独立文件**：图片、视频、图形、样式、Reveal.js、中文备注全部内嵌；只复制这一个文件到授课电脑即可。

19 页 / 30 分钟。英文投影，中文备注。深色底、青绿 / 橙色配色沿用第一部分；新版以图片和图示为主，细节移入备注。

## 主线

从同事“给 AI 一个身体”的结尾出发：

**为什么需要空间 → AI 帮助构建与理解 → 协作完成真实任务 → 身体与多端延续 → AI 学习、验证与未来想象。**

贯穿任务：“我想做一个实验室纪念模型，你能帮我完成吗？”

核心立意：不是为了复制实验室，而是让人与 AI 在同一个空间中理解任务、尝试方案、协作影响现实。四个 AI 角色：帮助构建、理解情境、协助行动、学习与验证。三维空间是否胜过列表/地图，以及 AI 是否真正改善任务结果，均作为待评价问题。

新增的虚实结合不是附录，是中段主线：
- 虚拟操作连接现实：3D 打印申请、审核、未来设备执行与反馈。
- 数字信息进入现场：AR 定位、导航、设备讲解和助手。
- 可信闭环：权限 / 确认 / 执行 / 观测，而不是把语言回答当作动作成功。

分段节奏与逐页主旨见 `内容脉络.md`；展开讲法见 `演讲备注.md`。

## 操作

- `→` / 空格 / 点击空白：下一页；`←` / 右键：上一页。
- `F`：全屏；`Esc` / `O`：总览；`B`：黑屏。
- `N`：当前页中文备注；`S`：独立演讲者窗口，含备注、下一页标题、计时和翻页。
- `H`：帮助；左下角有等效按钮。
- 第 3 页内嵌 `assets/wholeVisit.mp4`，静音自动播放并循环；下方链接打开部署的 Web Experience。
- 若浏览器阻止弹窗，允许弹窗或按 `N` 查看备注。
- PDF：地址加入 `?print-pdf`（放在 `#` 之前），刷新后打印；横向、无页边距、开启背景图形。
